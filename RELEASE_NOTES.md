# zqverify 1.0.0 release notes

This is the first release candidate synchronized with the quotient-detector manuscript v6.

Compared with the recoverable historical v0.1 cyclic-only archive, v1.0.0 adds:

- arbitrary products of cyclic groups;
- exact subgroup enumeration and quotient classes;
- cyclic/noncyclic quotient detection;
- signed and weighted quotient word metrics;
- detector optimization over arbitrary subgroup kernels;
- multicolour signed-current sources;
- the manuscript's deterministic quotient-source extraction, including the deliberately non-monotone defect rule;
- projected-filling BFS/Dijkstra checks on small rectangles;
- formal history-level activity checks;
- exact positive-character Fourier coefficients;
- exact 2D rectangle Wilson expectations and tiny-volume flux enumeration;
- a 9,156-case small-group detector catalogue;
- the 214-case direct finite-volume Wilson-versus-detector audit.

The code is supplementary verification, not a formal proof of the volume-uniform analytic theorems.
